SNP solutions from GBLUP
========================

Model
-----

We can back-solve the SNP effects from the GBLUP solutions for breeding values, that is, direct genomic values (DGVs). A simple formula for obtaining the SNP effects is based on best linear prediction (BLP) and, equivalently, a generalized selection-index formula. See the textbook and Wang et al. (2012) for details.

The author of the textbook calculates the SNP effects for the data used in the previous section. We will perform the same computation using POSTGSF90, an additional tool for computing SNP effects from the solutions produced by BLUPF90+. Here, we demonstrate how to perform a "post-GBLUP" analysis using the BLUPF90 programs.

Files
-----

The GitHub repository provides the files (`mr114.dat`, etc.) required for this analysis. These files are identical to those used in the previous section (`mr113.dat`, etc.). The procedure for predicting SNP effects is as follows.

1. Run BLUPF90+ (`blupf90+`) and obtain the breeding-value solutions in `solutions`.
2. Run POSTGSF90 (`postGSf90`) with the same parameter file.

Note that POSTGSF90 does not accept some options that are effective for BLUPF90+. For example, POSTGSF90 will stop if the parameter file contains `OPTION solv_method FSPAK`. You must remove such options before running POSTGSF90.
