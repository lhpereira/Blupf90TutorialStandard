Actual genetic evaluations often involve large data sets. Although the program `blupf90+` can read relatively large data and pedigree files (for example, files containing 1 million animals, depending on the available memory), it may fail in large-scale analyses involving tens of millions of individuals. Specialized software is available for such analyses under special arrangements with the development team at UGA. Members of the team can access and test software that supports large data sets. In this chapter, we explain how to use programs for large-scale genetic evaluations. Note that this tutorial also covers several options available in the public software.

The UGA team continuously updates and integrates programs for large-scale applications. Because the author does not have access to the large-scale software, this tutorial covers only the basic features implemented in the software. Recent developments can be found on the official DokuWiki maintained by the team.
